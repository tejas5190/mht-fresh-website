# MHT Fresh Corporate Website Prototype

This is an isolated front-end prototype stored separately from the existing website files.

## Run locally
Open index.html in Chrome or Edge. No build tools or package installation are required.

## Included
- Responsive corporate homepage
- About, trade services, supplier and buyer sections
- Filterable fruit catalogue and variety selection
- Interactive six-section product-book reader
- Previous/next navigation, keyboard arrows and print/save as PDF
- Enquiry form using a mailto fallback

## Important limitations
- This is a prototype, not a production CMS.
- Product and variety entries are starter examples, not an exhaustive catalogue.
- Technical content is deliberately marked research pending; no unsupported numerical values are invented.
- The enquiry form opens the visitor's email app; it does not submit to a server.
- Replace the placeholder enquiry email in app.js with a verified MHT Fresh email before public use.
- Replace emoji illustrations with appropriately licensed fruit and operations photography.
- No certifications, legal identifiers, owned facilities, supplier contracts or live stock claims are made.
- No production deployment or DNS changes have been made.
